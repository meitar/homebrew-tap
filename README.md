# meitar/homebrew-tap

Official Homebrew tap for [Aula F108 Pro macOS Companion Driver](https://github.com/meitar/aula-driver).

## How to Install

```bash
# Add this tap
brew tap meitar/tap

# Install the CLI tool
brew install aula-cli

# Or install the GUI application (once release asset is published)
brew install --cask aula-driver
```

## How to Update

```bash
brew update
brew upgrade aula-cli
```
